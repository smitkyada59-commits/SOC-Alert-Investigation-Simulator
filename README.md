# SOC Alert Investigation Simulator — L1 to L2

A cybersecurity portfolio project documenting a simulated brute-force alert investigation, from Level 1 (L1) triage and escalation to Level 2 (L2) investigation, response review, and incident closure.

## 📌 Project Overview

This project demonstrates a SOC workflow using a simulated **Brute Force Attack Detected** alert. The walkthrough includes seven failed login attempts, alert classification, L1-to-L2 escalation, threat intelligence review, simulated response options, and final case documentation.

## 🎯 Scenario Details

- **Alert Name:** Brute Force Attack Detected
- **Severity:** High
- **Category:** Credential Access
- **Failed Login Attempts:** 7
- **Source IP:** `192.168.1.105`
- **Destination IP:** `10.0.0.5`
- **Classification:** True Positive within the simulator scenario

## 🔍 Investigation Workflow

1. Review the L1 SOC dashboard.
2. Select the alert from the alert queue.
3. Investigate the alert details and authentication events.
4. Classify the alert and document the L1 case report.
5. Escalate the alert to L2.
6. Review the escalated alert in the L2 dashboard.
7. Analyze the event timeline and threat intelligence.
8. Review available simulated response actions.
9. Document the final investigation and remediation.
10. Close the alert in the simulator.

## 🚨 Incident Response Actions

The simulator provides the following response options:

- Block IP
- Disable Account
- Isolate Endpoint
- Terminate Session

These are simulated response options and do not indicate that real systems were modified.

## 📚 Key Learnings

- Understanding the responsibilities of L1 and L2 SOC analysts.
- Identifying suspicious authentication activity.
- Investigating brute-force alerts.
- Documenting findings and classifying alerts.
- Escalating incidents for deeper investigation.
- Reviewing threat intelligence and incident timelines.
- Following a structured incident-handling workflow.

## ⚠️ Project Scope

This is a **simulator-based SOC investigation walkthrough**, not a production SOC platform. It does not currently demonstrate a live SIEM integration, automated log ingestion, or verified real-world response actions.

The IP addresses and event details represent the scenario documented in the simulator.
